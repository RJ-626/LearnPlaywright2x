# VS Code Keyboard Shortcuts – Mac

## General

| Shortcut | Action |
|----------|--------|
| `Cmd + Shift + P` | Command Palette |
| `Cmd + P` | Quick Open (Go to File) |
| `Cmd + Shift + N` | New Window |
| `Cmd + W` | Close Window |
| `Cmd + ,` | User Settings |
| `Cmd + K Cmd + S` | Keyboard Shortcuts |
| `Cmd + Shift + T` | Reopen Closed Editor |
| `Cmd + Shift + Tab` | Open Previous Editor |
| `Cmd + Tab` | Open Next Editor |
